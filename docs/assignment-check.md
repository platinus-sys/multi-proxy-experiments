# Сверка с тестовым заданием

| Требование | Результат и границы проверки |
| --- | --- |
| 1. Совместная карта | Полный S3E College, 877,626 с, три робота. В отчёте указаны Co-LRIO, входные топики, системы координат и синхронизация по меткам. Общая карта, траектории и скриншоты RViz встроены. Жёлтый слой содержит принятые ограничения iPCM, а пример межроботной проверки идентифицирован по журналу ICP. |
| 2. Три условия связи | По три полных прогона без помех, с задержкой 100 мс и с потерями 1%. Параметры и счётчики сохранены. Для каждого режима в отчёте есть карта с траекториями, участок перекрытия 40 × 40 м и таблицы времён, трафика и ATE. |
| 2. Сопоставимость | Хеши bag и бинарника, launch, конфигурация, параметры сети и список ROS-узлов сверяются при объединении серий. Для ATE используется один SE(3) на всех роботов в каждом прогоне. Смещение RTK–LiDAR и соответствие Alpha/Bob/Carol требуют внешней проверки. |
| 2. Время и трафик | Измерены воспроизведение, ожидание, сохранение, итерации глобальной оптимизации и наблюдаемая устойчивость. Полное исчерпание очередей и сходимость не измерены. Счётчики tc включают часть входного и служебного трафика. Три повтора позволяют оценить разброс на стенде. Статистическая значимость не установлена. |
| 3. Вклад оптимизации | Отдельные проходы с отключённым обнаружением соседей и с блокировкой четырёх типов межроботных сообщений на 400–520-й секундах. В отчёте есть двусторонние 3D-расстояния между поверхностями, двойные контуры, состояния до и после разрыва и время возобновления сообщений. Heartbeat сохранялся. Повторов для оценки разброса в этой части нет. |
| Материалы | Архитектура, оборудование, версия исходников, команды и ограничения включены в отчёт. Multi-Proxy запускается на подготовленном входе, версия настроек Co-LRIO неизвестна. К отчёту приложена локальная запись RViz длительностью 94,6 с. |
| Формат сдачи | DOCX со встроенными иллюстрациями подготовлен. Публикация Google Doc и доступ по ссылке для видео остаются открыты до подключения Google Drive или предоставления другого места публикации. |

Команды подготовки, запуска и анализа находятся в [инструкции по воспроизведению](reproduction.md).
